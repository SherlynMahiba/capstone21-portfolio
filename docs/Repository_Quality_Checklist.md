# Repository Quality Checklist

- [ ] Clear repository name and description
- [ ] README explains purpose and features
- [ ] Installation/setup steps are complete and tested
- [ ] Usage examples are accurate
- [ ] Tests and test commands are documented
- [ ] Links work
- [ ] Folder and file names are consistent
- [ ] No passwords, tokens, or private information are committed
- [ ] Dependencies and versions are documented
- [ ] Licence is present and appropriate
- [ ] CONTRIBUTING instructions are clear, if needed
- [ ] Code of Conduct is respected, if present
- [ ] Issues and pull requests are respectful and focused
