# First Open-Source Contribution — Beginner Guide

## Before you start
Read the repository's README, CONTRIBUTING file, Code of Conduct, licence, and issue discussion. Check that the project accepts contributions and that the issue is still available.

## Workflow
1. Find a small issue that matches your skills.
2. Comment politely to confirm you can work on it, if the project expects that.
3. Fork the repository when required.
4. Clone your fork: `git clone <your-fork-url>`
5. Open the project folder: `cd <repository-folder>`
6. Create a branch: `git switch -c docs/short-description`
7. Make one focused change.
8. Inspect your changes: `git diff`
9. Run the documented checks or tests.
10. Stage and commit: `git add .` and `git commit -m "docs: describe the change"`
11. Push: `git push -u origin docs/short-description`
12. Open a pull request. Explain the problem, solution, and tests.
13. Respond constructively to review feedback.

## Important reminders
- Never commit secrets or private data.
- Do not copy code or documentation without respecting its licence.
- Do not submit AI output that you cannot explain.
- Do not claim tests passed unless you ran them.
- Follow the project's own instructions; projects may use a different workflow.
